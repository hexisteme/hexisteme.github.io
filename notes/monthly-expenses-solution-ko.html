학교·기관 월별 지출 CSV 집계: 원본을 보존하는 로컬 변환기

먼저 확인할 답

일자·항목·금액 열이 있는 CSV를 월·항목·건수·합계로 묶으려면 이 로컬 도구를 실행하세요. 원본 파일을 그대로 두고 새 집계 파일을 만듭니다. 학교·기관에서 매월 지출 내역을 내부 보고용으로 다시 묶는 담당자를 위한 평가 패키지입니다.

어떤 반복 작업을 줄이나요

내보낸 내역의 행별 날짜를 보고 월을 정하고, 같은 항목끼리 모으고, 환불을 빼서 합계를 만드는 작업을 코드로 옮겼습니다. 여러 기관이 겪는 공통 불편이라는 가설에서 출발했으며 실제 담당자 인터뷰나 시간 절감은 아직 측정하지 않았습니다. 이 열 계약과 다른 파일은 먼저 익명 서식으로 지원 가능 여부를 확인하세요.

지원하는 입력과 결과

입력 열 이름과 순서는 일자,항목,금액입니다. 날짜는 하이픈으로 구분한 연·월·일, 금액은 쉼표 없는 십진수로 넣고 환불은 음수로 표시합니다. 항목에 수식처럼 시작하는 문자열이나 제어 문자가 있으면 거부합니다. 출력은 월,항목,건수,합계 순서의 UTF 인코딩 CSV입니다. 빈 입력·잘못된 날짜·허용 범위 밖 금액은 출력 전에 거부합니다. 항목 이름을 자동으로 통일하거나 영수증을 판독하지 않습니다.

합성 자료로 확인한 결과

동봉한 합성 예제 3행을 실행하면 2개 그룹을 만듭니다. 인쇄용지 합계는 11000.00원, 수업소모품 합계는 8000.00원입니다. 이 결과는 고객 자료나 업무 성과가 아닌 패키지 생성 시의 로컬 실행 관측입니다. 입력·출력·실행 코드의 해시는 근거 파일에 보존했습니다.

실행 순서

Python이 설치된 로컬 컴퓨터에서 도구 다운로드와 합성 예제 파일을 같은 작업 폴더에 저장하세요. 먼저 예제를 실행하고 동봉한 기대 결과와 비교하세요.
python3 monthly-expenses.pyz --input expenses.csv --output monthly.csv
실제 파일을 사용할 때는 원본의 사본을 준비하고 새 출력 경로를 지정하세요. 완료 후 원본 행·환불·항목별 합계를 담당자가 대조하세요.

오류가 나면

output already exists이면 다른 출력 이름을 지정하세요. invalid 일자·항목·금액이면 표시된 행과 열을 로컬에서 점검하세요. 오류 메시지에는 셀 값이 들어가지 않습니다. 입력과 출력 전체를 운영자에게 보내지 말고 열 이름·오류 코드·민감정보를 제거한 재현 표본만 준비하세요. 원본을 덮어쓰는 옵션은 제공하지 않습니다.

도입 범위와 연간 라이선스

평가 후 기관 단위로 반복 사용하려면 연간 라이선스 범위와 도입 요청서를 확인하세요. 제안 범위는 지정 기관의 내부 사용, 지원 서식 계약, 오류 수정 및 계약 기간의 업데이트입니다. 가격·납기·응답 시간·회계 증빙은 서식 적합성을 확인한 뒤 별도 합의합니다. 이 패킷에는 활성 결제나 자동 접수 기능이 없으며 구매·납품 완료를 뜻하지 않습니다.
