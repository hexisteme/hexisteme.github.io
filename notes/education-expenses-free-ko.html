교육 지출 XLSX 월별 집계·검산 — 무료 로컬 도구

먼저 확인할 답

지원 서식의 교육 지출 XLSX를 월·분류별로 다시 묶어야 한다면 무료 로컬 도구를 사용할 수 있습니다. 새 엑셀 결과에 월별집계와 검산 시트를 함께 만듭니다. 결제·가입·기관 문의·원본 제출 없이 ZIP을 내려받습니다. 범용 엑셀 자동 변환기가 아니므로 자신의 파일이 아래 입력 계약에 맞는지 먼저 확인하세요.

어떤 파일에 사용할 수 있나요

서울 동부 교육지원청의 공개 교육 지출 서식에서 관측한 한 가지 계약을 지원합니다. 서식 시트, B열 집행일자, C열 유형별 구분, G열 금액, 지정된 머리글과 마지막 합계 수식 형태를 검사합니다. 정확한 프로필과 머리글 위치는 동봉 안내를 확인하세요. 숨겨진 C열 분류도 그대로 사용하므로 분류의 업무상 의미는 담당자가 확인해야 합니다. 다른 기관의 열을 자동 추정하거나 나이스·ERP 업로드 서식을 완성하지 않습니다.

다운로드한 뒤 처음 실행하기

Python 3.11 이상과 openpyxl 설치가 필요합니다. 터미널에서 압축을 푼 폴더로 이동한 뒤 아래 설치 명령과 예제 확인 명령을 실행하세요. 설치는 의존성 다운로드에 인터넷이 필요합니다. 기관 PC의 설치 정책을 우회하지 마세요.
python3 -m pip install 'openpyxl>=3.1.5,<4'
python3 education-expenses-free.pyz --check-example
EXAMPLE_MATCH와 synthetic_only가 표시되면 동봉한 합성 예제만 일치한 것입니다. 자신의 업무 파일을 검사한 결과가 아닙니다.

합성 예제에서 실제 확인한 값

합성 입력 3행이 2개 그룹으로 집계됐습니다. 교육 분류는 2000원, 행정 분류는 800원, 엑셀의 전체합계 셀은 2800원으로 관측했습니다. CSV 기대 바이트와 엑셀 셀·검산 결과도 대조했습니다. 합성 결과 미리보기는 아래 별도 링크로 열 수 있습니다. 고객 자료, 업무 시간 절감, 오류 감소나 실제 수요를 측정한 결과는 아닙니다.

내 파일을 월별 결과로 만들기

처리 권한이 있는 원본의 사본을 사용하고 새 출력 이름을 지정하세요. 아래 입력 이름을 자신의 파일 이름으로 바꾸되 띄어쓰기가 포함되면 따옴표를 유지합니다.
python3 education-expenses-free.pyz --input "authorized-source.xlsx" --output "monthly-new.xlsx"
엑셀 대신 CSV가 필요하면 형식과 새 이름을 명시하세요.
python3 education-expenses-free.pyz --input "authorized-source.xlsx" --output "monthly-new.csv" --format csv
원본과 기존 결과는 덮어쓰지 않습니다. 사용 후 실제 원본 행·환불·분류 의미를 담당자가 확인하세요.

검산이 보장하는 것과 하지 않는 것

검산 시트는 검증된 입력 행과 각 월·분류의 건수·금액이 일치하는지 대조합니다. 원본 엑셀 합계 수식의 캐시 계산값을 검증하는 기능은 아닙니다. 전체합계는 입력 전체의 값이므로 필터를 바꿔도 다시 계산되지 않습니다. 공식 제출물 완성, 회계 판단, 기관 보안 감사나 임의 서식 호환성을 보증하지 않습니다. 금액이 엑셀의 정밀도 계약을 넘으면 거부하며 CSV를 선택할 수 있습니다.

오류가 나면 무엇을 확인하나요

output already exists이면 새 출력 이름을 사용하세요. missing dependency: openpyxl이면 설치 상태를 확인하세요. invalid header/sheet/summary이면 지원 계약과 다른 파일입니다. row ... invalid B/C/G이면 표시된 행의 날짜·분류·정수 금액을 로컬에서 확인하세요. 집계 결과에는 월·분류·건수·금액이 남으며 목적·참석자·장소·부서와 원본 경로는 넣지 않습니다. 오류 안내에는 셀 값과 원본 경로를 표시하지 않습니다. 민감한 원본을 운영자에게 보낼 필요가 없습니다. 강제 종료나 운영체제가 정리를 거부하는 경우의 임시 자료 정리 한계는 남습니다.

설치 환경과 무료 사용 범위

실제 실행 확인은 Mac의 합성 예제에 한정됩니다. Windows와 기관 PC 설치는 아직 확인하지 않았습니다. Python이 필요한 스크립트 패키지이며 설치 없는 응용 프로그램은 아닙니다. 전달된 무료 버전에는 사용 기간 제한을 두지 않습니다. 맞춤 서식, 기관 전체 지원 계약, 재판매 권한과 지속적인 업데이트를 포함하지 않습니다. 변환 코드에는 네트워크 전송·광고·추적이 없으나 설치·브라우저·운영체제·클라우드 동기화의 동작은 별개입니다.
