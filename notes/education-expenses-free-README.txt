# 교육 지출 월별 집계 — 무료 로컬 도구

문의·가입·결제·원본 제출 없이 사용합니다. 본인에게 처리 권한이 있는 파일만 사용하세요.
AI를 사용해 도구와 안내를 작성했습니다. 실행 예제는 합성 자료이며 고객의 절감 시간은 미측정입니다.
다운로드 ZIP에는 광고 코드·추적·결제 기능이 없습니다. 광고 수익은 블로그의 별도 운영 사항입니다.

## 처음 시작

1. ZIP을 로컬 폴더에 압축 해제합니다. 클라우드 동기화 전송은 도구가 통제하지 않습니다.
2. Python 3.11 이상이 필요합니다. 터미널에서 python3 --version을 확인하세요.
3. 설치는 별도 명령이며 의존성 다운로드에 인터넷이 필요합니다:
   python3 -m pip install 'openpyxl>=3.1.5,<4'
4. 터미널에서 cd 뒤에 압축 해제 폴더 경로를 지정합니다. 공백이 있는 경로는 따옴표로 감쌉니다.
5. 먼저 동봉 예제만 자동 검사합니다. 이 명령은 자기 파일을 받지 않고 임시 작업을 정리합니다:
   python3 education-expenses-free.pyz --check-example
   EXAMPLE_MATCH와 synthetic_only: true는 합성 예제 일치만 뜻합니다.

macOS/Python 3.13.0/openpyxl 3.1.5에서 실제 실행 검증했습니다.
최소 버전 표기는 모든 환경의 실행 확인이 아닙니다. Windows·기관 PC 설치는 미검증입니다.
명령 이름은 환경에 따라 python3 대신 python 또는 py일 수 있습니다. 설치 권한을 우회하지 마세요.

## 내 파일 처리

python3 education-expenses-free.pyz --input "authorized-source.xlsx" --output "monthly-new.xlsx"

기본 결과는 엑셀 월별집계·검산 시트입니다. 열 필터, 제목 고정, 금액 형식을 제공합니다.
전체합계는 입력 전체 값이며 필터를 선택해도 다시 계산되지 않습니다.
sample-report.xlsx는 합성 예제의 결과 미리보기입니다. 자기 파일의 결과로 사용하지 마세요.
CSV가 필요한 경우에는 형식을 명시합니다:

python3 education-expenses-free.pyz --input "authorized-source.xlsx" --output "monthly-new.csv" --format csv

지원 프로필은 seoul-dongbu-expenses-2025-07-v1 한 가지입니다.
서식 시트/헤더14행/B집행일자/C유형별 구분/G금액, 마지막 합계 SUM 형태를 검사합니다.
숨김 C열의 분류를 그대로 사용하므로 업무 분류가 맞는지는 사용자가 확인합니다.
목적·참석자·장소·부서와 원본 경로는 결과에 넣지 않습니다. 임의 XLSX·나이스/ERP 업로드는 지원하지 않습니다.
검산은 검증된 입력 행과 각 월·분류의 건수·금액을 대조합니다. 원본 합계 수식의 계산값 대조가 아닙니다.
공식 제출 서식 완성·기관 보안 감사·회계 판단을 대신하지 않습니다.

## 오류를 확인할 때

원본과 기존 결과는 덮어쓰지 않습니다. 출력이 이미 있으면 새 이름을 지정하세요.
row ... invalid B/C/G: 표시된 행의 날짜/분류/정수 금액을 로컬에서 확인합니다.
invalid header/sheet/summary: 지원 서식과 다른 파일입니다. 열을 자동 추정하지 않습니다.
missing dependency: openpyxl: 설치를 확인합니다. XLSX 금액 정밀도 범위 초과 시 CSV를 사용합니다.
정상 exit0, 거부 exit2입니다. 셀 값이나 경로가 없는 코드만 안내하며 원본 제출은 필수가 아닙니다.
변환 코드는 네트워크 전송을 하지 않습니다. 설치 다운로드·OS·동기화 프로그램의 동작은 별개입니다.
강제 종료나 OS가 정리를 거부하는 경우의 임시 자료 정리 한계는 남습니다.
